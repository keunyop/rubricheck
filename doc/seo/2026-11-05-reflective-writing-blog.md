# 네 번째 블로그: What? → So what? → Now what? 반성적 글쓰기

조사·작성일 2026-11-05. 기존 세 글의 URL과 발행일은 유지하고 새 글 한 편을 추가한다.

## 선택과 제품 연결

- `/blog/reflective-writing-what-so-what-now-what` — **Reflective Writing Example: Move from What? to So What?**
- 영어. 말레이시아의 영어 과제 작성 대학생을 우선 가설로 두고 영국의 reflective assignment 독자, 호주의 국제학생 맥락도 검토했다. 국가별 검색어 실적이나 전환 우위를 확인한 선택은 아니다.
- **신규 수요 실험**이다. 기존 `descriptive-vs-critical-analysis`는 외부 자료를 해석하는 에세이 문단, 새 글은 자신의 경험을 사건→의미→검증 가능한 다음 행동으로 바꾸는 반성적 글쓰기를 다룬다.
- 가상의 그룹 발표 사례, 약한 문단과 개선 문단, 기준별 증거 표, 10분 점검을 제공한다. 실제 학생·과목·후기·성과가 아니다.
- 실제 기능은 `/workspace?start=general&from=blog-reflective-writing#rubric-checker`. 과제 지시사항과 실제 루브릭을 함께 넣도록 안내하고, 일반 기준은 학교 채점 기준이 아니라고 설명한다. AI 평가가 공식 성적·인용 검증·기밀정보 처리 허가를 제공한다고 주장하지 않는다.
- 첫 문단에서 What은 필요한 사건만, So what은 피드백·관점·수업 근거로 의미를 해석하고, Now what은 관찰 가능한 행동과 확인 방법으로 쓰라고 바로 답한다. 세 질문은 보편적 채점표가 아니며 실제 과제 지시와 루브릭이 우선임을 명시한다.

## 공개 조사와 한계

- Google 검색 `reflective writing what so what now what example`을 `hl=en&gl=my`로 직접 확인했다. 대학 가이드, PAA와 `academic reflective writing examples`, `how to write a reflection on an assignment` 같은 관련 검색이 나타났다. 이는 질문 표현과 경쟁 결과 표본이지 검색량이 아니다.
- [University of Sheffield](https://sheffield.ac.uk/study-skills/university/independent/reflect): reflective writing은 경험을 분석하고 향후 수행을 개선하는 과정이며 분야별 지시와 marking criteria 확인이 필요하다. What? So what? Now what? 모델도 소개한다.
- [University of Reading](https://libguides.reading.ac.uk/reflective/writing): 2026-09-04 갱신 페이지. 서술을 짧게 하고 통찰, 이론·실천 연결, 구체적 다음 계획에 공간을 쓰라고 안내한다.
- Google의 말레이시아 결과 화면은 확인했지만 로그인·개인화되지 않은 한 시점의 표본이다. 자동완성 전체, Keyword Planner, 절대 검색량, 국가별 쿼리 GSC, 전환율 자료는 없다. Google AI Overview의 수치·주장은 사실 근거로 사용하지 않았다.
- 경쟁 결과가 충분하므로 낮은 경쟁이나 정보 공백을 주장하지 않는다. 이번 차별점은 한 가상 사례를 실제 루브릭 증거 질문과 RubriCheck 동선까지 연결하는 데 있다.
