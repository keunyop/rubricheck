## 2026-11-10 성장·퀴즈 실험 기준

최신 정정: CONTENT-001은 2026-11-10 사용자로부터 검증 후 블로그 글을 별도 승인 없이 게시할 권한을 받았다. 위의 승인 대기 문구는 이전 상태다. GRADE-001의 관리자 보관함은 기존 비밀키 인증으로 확인했고, 배점 합계 불일치 또는 항목 배점 없는 기준표가 반복 구조화 실패와 연결됐다. 점수를 임의 보정하지 않고 사용자 안내를 보강했다. QUIZ-001 관리자 집계도 실제 생성·연습이 존재함을 확인했으며 초기 표본이므로 노출 문제와 기능 문제의 인과 구분은 추후 공개 퍼널 수집으로 판단한다.

- SEO-001: 영어 기존 페이지를 미국 우선·호주/캐나다 보조로 관찰하며 말레이시아 기반을 유지한다. 신규 번역/광고 비용 없음. 검색 의도와 제품의 불일치 수정이 최소 범위다. 잘못된 무료 범위 안내·CTA 오류가 발견되면 해당 문구/링크를 복구한다.
- QUIZ-001: 기존 샘플 체험 위치에서 생성으로 이어지게 한다. 노출→선택→샘플→생성 클릭은 GA4 공개 화면 관측이며 관리자 생성/학습 집계와 동일한 사용자 퍼널이 아니다. 모델 실행·가격·무료 한도·DB migration 없음. 추적 동의 위반·private 정보 전송·UI 방해 시 즉시 revert한다.
- GROW-002: 성공한 다른 attempt를 두 번째 사용으로 정의한다. 기존 수집 시작 이전의 결측을 0으로 채우지 않는다. 가입 후 관찰 기간과 동의 누락을 명시한다. 11월 17일 경로 확인 후 12월 8일 재사용·실제 구독 결과를 보고 다음 변경을 정한다. 표본이 부족하면 관찰 연장, 근거 없이 가격·무료 한도를 변경하지 않는다.

## 변경 평가와 복구

QUAL-001 대상은 소수 배점 rubric 사용자, 근거는 실제 schema를 통과한 합성 재현이다. 성공 기준은 `0 <= score <= max_score`와 기존 정수 점수 계약 유지다. 예상 효과는 배점 초과 출력 제거이며 전환 개선 수치는 미측정이다. 추가 API 비용/마이그레이션 없음. 소수 점수 자체 지원은 별도 설계 과제다. 배포 전 실패 시 두 상한 변경과 회귀를 되돌린다. 배포 후 이상 시 승인된 롤백 절차로 직전 검증 배포를 복구한다.

GROW-001은 퀴즈 랜딩 유입을 기존 수집 범위에서 누락하지 않게 한다. 정확한 유입 집계가 목적이며 신규 수집 동의/이벤트/무료 한도는 변경하지 않는다. 기존 analytics 전송량의 누락 복구분은 증가할 수 있으나 금액 미측정이다. private 경로나 쿼리가 유출되면 즉시 배포 중단/복구한다. 공개 경로 한 항목과 회귀만 되돌릴 수 있다.

초기 완료 작업은 OPS-001·QUAL-001·GROW-001이다. BILL-001의 과거 실패는 원천 대조를 마쳤고, DATA-001의 고유 평가 결과는 미완료다. SEC-008의 기존 PR 상태는 별도 확인 대상으로 유지한다. 확인 기한은 [state](state.json)에 둔다.
