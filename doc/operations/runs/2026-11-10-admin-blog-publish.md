## 관리자 진단

- production 관리자 실패 목록·상세 읽기 API가 인증 헤더로 200을 반환했다. 이 보관함은 7일 진단 이력이며 건수가 현재 미해결 사용자 수를 뜻하지 않는다. 실제 내용은 비공개 owner 기록에만 요약한다.
- 최근 반복 구조화 실패는 항목별 점수 합계와 문서 총점이 일치하지 않는 기준표에서 발생했다. 다른 기준표에는 총점만 있고 행별 점수 배분이 없었다. 모델 출력 검증은 이런 경우 임의의 점수 배분이나 조용한 총점 변경을 막는다. 로그의 `total_score` 검증 실패와 원문을 대조했다.
- 사용자 안내에 배점 합계 확인, 배점 내역 문의, 텍스트 입력·선명한 파일 재제출을 함께 제시한다. 일곱 언어 문구를 갱신했다. 원본 수정·점수 자동 보정·보관함 삭제는 하지 않았다. 실제 재요청 성공률은 후속 관찰 대상이다.
- 퀴즈 관리자 생성·학습 집계를 인증된 읽기 API에서 확인했다. 기능 미사용 0건 가설은 사실이 아니며, 낮은 이용 원인은 최근 도입 기간과 노출→클릭→생성 계측이 더 쌓인 뒤 판단한다.
